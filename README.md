# 전북대학교 농업수문학연구실 홈페이지

별도 설치가 필요 없는 정적 웹사이트입니다.

## 파일

- `index.html`: 글과 화면 구성
- `style.css`: 색상, 크기, 배치
- `script.js`: 모바일 메뉴와 스크롤 효과
- `jbnu-signature-blue.png`: 전북대학교 로고
- `professor-sanghyun-lee.png`: 교수 사진

## 다른 컴퓨터에서 수정하기

1. GitHub Desktop에서 저장소를 Clone 합니다.
2. VS Code에서 폴더를 엽니다.
3. 위 세 파일을 수정합니다.
4. GitHub Desktop에서 Commit 후 Push 합니다.

Node.js, npm, 터미널, Live Server 설치가 필요하지 않습니다. 확인할 때는 `index.html`을 더블 클릭하면 됩니다. Push하면 GitHub Pages가 자동으로 배포합니다.
